你的账本，保存在这里

收支和预算保存在当前浏览器的本地存储中，不会上传到服务器。其他访客打开这个工具，看到的是他们自己的账本。

换设备、换浏览器、换网站地址、使用无痕窗口或清除网站数据时，账本不会自动同步。建议通过“数据管理 → 导出 JSON 备份”定期保存，之后可导入恢复。

CSV 用于表格查看，恢复账本请使用 JSON 备份。此版本不连接银行卡，不需要登录；同一浏览器账户的使用者可能访问普通账本中的本地记录。

左上角的小账本图标可进入秘密基地。秘密基地设置独立密码，加密保存，不计入普通账本的统计、预算或导出。密码遗失无法找回，请单独保存加密备份；切到后台、刷新或 5 分钟未操作会锁定。
